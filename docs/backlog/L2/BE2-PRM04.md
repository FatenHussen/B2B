# BE2-PRM04 — Indivisibility and quota reservation

## Requirements

1. Every line generated by one offer carries a shared promotion group id; removing any removes the whole group (BR-08).
2. Offer quota is reserved alongside stock at confirmation to prevent overshoot.
3. An expired or exhausted offer is removed from unsent carts with a notice before confirmation (BR-20).

## Acceptance criteria

_Write one test per criterion. Name the test after the criterion._

- [ ] Deleting one bundle line deletes every line of that bundle in one operation.
- [ ] Two simultaneous carts cannot consume the same last unit of quota.

## Working rules

- Touch only `app-modules/promotion` and its tests.

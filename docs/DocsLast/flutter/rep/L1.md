# Rep — Layer 1 (identity)

| | |
|---|---|
| Backend | SP-01 · SP-03 refs · SP-04 `channel_id` |
| Kit | [`../../_shared/flutter-client.md`](../../_shared/flutter-client.md) |

Prove the phone, attach to **one** supply channel (invite), wait for review. Not a catalog or map.

---

## Scaffold

```bash
flutter create --org sy.b2b --platforms=android,ios --project-name rep_app apps/rep
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000/api/v1
```

`applicationId` `sy.b2b.rep` — must differ from retailer. Storage key prefix `rep.`.

Deep link: `b2b-rep://register?channel_id=1&channel_name=Demo%20Channel`  
Android intent-filter + iOS URL type `b2b-rep`. Hold `channel_id` in `InviteController` until register succeeds.

`GET /public/refs` does **not** list channels. Do not call `/platform/channels`. Without `channel_id`: copy only — «استخدم رابط الدعوة من شركتك».

---

## Phone / OTP

Same as retailer: `POST /public/auth/request-otp|verify-otp|resend-otp` with `client` `rep-android` / `rep-ios`.

---

## Register — `FE-RP-REGISTER`

`POST /app/rep/register` · Bearer + idempotency.

| UI | Key | Widget |
|---|---|---|
| Name | `name` | Field |
| Channel | `supply_channel_id` | **Read-only** from invite |
| Activity | `activity_type_id` | Refs |
| Zones ≥ 1 | `zone_ids` | Chips from refs |
| Note | `note` | Optional |

422 zone outside coverage → field error. 409 channel not `active` → banner. Then waiting via `GET /app/session`. Logout same wipe rules as retailer.

Empty home (approved): name + **channel name** + «المهام بعد الموافقة».

---

## Out of scope

Products, customers, carts, assignments, wallet, live location.

## Zone shops + cart — `FE-RP-SELL` (SP-09)

`GET /app/rep/zones/{id}/shops` · EP-RP-020 — shops in a covered zone.

Cart is **per retailer**:

| Method | Path | EP |
|---|---|---|
| POST | `/app/rep/cart/lines` | EP-RP-021 |
| GET | `/app/rep/cart` | EP-RP-022 |
| POST | `/app/rep/cart/sections/{retailer_id}/submit` | EP-RP-023 |

Prices from the engine for **that shop’s zone**. `discount_percent` ≤ channel cap or 403 `discount_cap_exceeded`. Submit creates one sub-order for this channel.

---

## Duty + assignments — `FE-RP-DUTY` (SP-10)

| Method | Path | EP |
|---|---|---|
| PATCH | `/app/rep/status` | EP-RP-034 `on_duty` — `tracking_enabled` only while on duty |
| GET | `/app/rep/assignments` | EP-RP-030 — **channel name allowed** |
| POST | `.../accept` `.../reject` | EP-RP-031/032 |
| GET | `/app/rep/scheduled-orders?date=` | EP-RP-033 |

Off-duty reps cannot be assigned (channel gets 422). Reject returns the order unassigned.

---

## Warehouse handover — `FE-RP-WH` (SP-11)

`GET /app/rep/warehouse-receipts` · EP-RP-040  
`POST .../{handoverId}/confirm` · EP-RP-041 `{ temp_code }`

Confirm **without** warehouse `POST /warehouse/handovers` → 409. Both sides: stock deduct + `on_the_way`. Repeat confirm is idempotent. Large numeric pad for the 4-digit temp code.

---

## Delivery — `FE-RP-DEL` (SP-12)

EP-RP-050…055 list/detail/line/complete/postpone/fail.  
EP-RP-056 location pings — max 1/30s, rejected if off-duty.  
EP-RP-057 field return.

Line PATCH is the **same row** the retailer sees (REQ-IN-05). Complete delivery issues `INV-*`. No payment posting here (L4).

---

## Out of scope (L4)

`POST /app/receipts/reserve`, collect, wallet, withdrawals.

## Done

2. Duty off → cannot accept a new assignment flow from channel.  
3. Handover confirm without warehouse open → 409.  
4. Line adjust updates invoice total.  
5. Pings while off-duty fail.

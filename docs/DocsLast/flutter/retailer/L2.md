## Gate

| Session | Route |
|---|---|
| L1 incomplete / waiting / rejected | L1 routes — **no catalog fetch** |
| `active` | `/home` this file |
| `403 profile_incomplete` | Back to L1 |

Bottom nav: **Home · Categories · Offers · Account**. Account = shop name + logout. No Cart / Orders tabs. Home chips with `count: 0` stay **disabled**.

Extend `packages/b2b_api` — no Dio in the app.

## Product card (bind this only)

Integers. `price.label` as returned. `availability` enum badge — **never** a stock qty. `sold_count` / `rating` may be 0. Dart model has **no** `supplyChannel`. Mapper drops extra keys.

---

## Screens

| ID | API | UI |
|---|---|---|
| `FE-RT-HOME` | `GET /app/retailer/home` **one** call | Header names real; points/cart/orders **0**. Empty zone → illustration, no fake SKUs |
| `FE-RT-CAT` | `GET /app/retailer/categories` | Drill `parent_id`; leaf → product list |
| `FE-RT-PLIST` | `GET /app/retailer/products` | search, filters, infinite scroll. Heart: `POST .../favorite` + idempotency |
| `FE-RT-PDETAIL` | `GET /app/retailer/products/{id}` | Gallery, MOQ, variants. Qty stepper → quote. 404 = gone, not «forbidden» |
| `FE-RT-BRAND` | `GET .../brands` `{id}` | Empty bestsellers OK |
| `FE-RT-SHORT` | GET/POST/DELETE `/app/retailer/shortages` | Isolated per shop |
| `FE-RT-OFFER` | `GET /app/offers` `{id}` | `company` always null. Prefer `days_left` from server |
| `FE-RT-QUOTE` | `POST /app/pricing/quote` | Body `{ lines, zone_id }` only. Show `applied_rule`. Qty-tier: cheaper `unit_price`, `discount` **0** |

Quote `zone_id` = shop zone. `product_not_available` → line error.

---

## Out of scope

Cart, orders, tracking, payments, debts, loyalty, GMV, channel names on SKUs.

## Done

1. Waiting shop never hits `/app/retailer/home`.  
2. Home is **one** GET.  
3. Other-zone product id → 404.  
4. No `supply_channel` on the model.  
5. Qty 6 on fixture tiers → quote `11500` / `qty_tier` / `discount` 0.  
6. Favorite retry uses the same idempotency key.

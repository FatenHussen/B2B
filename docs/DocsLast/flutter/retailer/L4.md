## Account — `FE-RT-FIN` (SP-13)

| Method | Path | EP |
|---|---|---|
| POST | `/app/retailer/payments` | EP-RT-050 `{ receipt_no, amount, … }` |
| GET | `/app/retailer/account/summary` | EP-RT-051 |
| GET | `/app/retailer/account/statement` | EP-RT-052 |
| POST | `.../statement/export` | EP-RT-053 → `job_id` |
| GET | `/app/retailer/debts` | EP-RT-054 |

Debts **may** show channel name (invoice exists). Amounts integers. Same `receipt_no` as a rep collection must **not** create a second payment (server duplicate). 409 if amount differs.

Enable the **Debts** chip on home. Summary month from server snapshots — do not N+1 orders on the device.

---

## Sync — `FE-RT-SYNC` (SP-14)

`GET /app/sync/pull` · `POST /app/sync/push` · status · resolve-conflict.

- Client **never** pushes catalog, prices, offers, or stock (REQ-CM-017).
- Outbox types: `cart.submit`, `payment`, `receipt`, `shortage`, `favorite`, `rating`.
- Same `client_op_id` → `duplicate` + existing `server_id`. Keep the row until `applied|duplicate`.
- Stale cursor → `full_resync_required` — wipe local catalog cache, pull again.
- Conflicts: default `server_wins` for money.

---

## Inbox — `FE-RT-INBOX` (SP-14)

`GET /app/notifications` (unread in `meta.unread_count`), mark read, hide (`DELETE` hides display only). `POST` push token. Banner on home uses the count — no fake 12.

---

## Home blocks + loyalty — `FE-RT-LOYAL` (SP-15)

`GET /app/content/home-blocks` fills L2 empty sliders (targeting by zone + activity).  
`GET /app/session` now has real `loyalty_accounts`.  
`GET /app/loyalty/wallet` · `POST /app/loyalty/redeem`. 423 `plan_limit_exceeded` if the channel plan has no loyalty. Points are integers.

Show `points` / `tier` on the header **only** from this payload — still no invented 1240 / silver.

| Name | Path | When |
|---|---|---|
| `splash` | `/` | Cold start |
| `phone` | `/phone` | No token |
| `otp` | `/otp` | Has `otp_id` |
| `register` | `/register` | Token, profile incomplete |
| `waiting` | `/waiting` | `pending_review` |
| `rejected` | `/rejected` | `rejected` |
| `home` | `/home` | Complete + `active` — **empty** in L1 |

`redirect` is the only gate. `GET /app/session` (EP-CM-004) on splash if a token exists.

Do not show `points` / `tier`. If `requires_legal_accept`, blocking copy is enough.

## Screens

### Phone — `FE-RT-PHONE`

`POST /public/auth/request-otp` · `{ phone, purpose: "login", client }`  
Accept `09XXXXXXXX` or `+9639XXXXXXXX` as typed. 422 on the field. 429 disables the button. Store `otp_id`, `resend_after`.

### OTP — `FE-RT-OTP`

`POST /public/auth/verify-otp` · `{ otp_id, code, device_id, device_name, platform }`  
Six digits. Resend: `POST /public/auth/resend-otp` `{ otp_id, prefer_channel }`.  
`otp_invalid`: clear boxes; do **not** request a new OTP. Persist `token`. New user → `/register`.

### Register — `FE-RT-REGISTER`

`GET /public/refs` then `POST /app/retailer/register` (Bearer + idempotency).

| UI | Key | Required |
|---|---|---|
| Owner / shop | `owner_name`, `shop_name` | Yes |
| Activity, categories (≥1), equipment | `activity_type_id`, `category_ids`, `equipment_ids` | categories yes |
| Governorate → zone | `governorate_id`, `zone_id` | Yes — changing governorate **clears** zone |
| Pin / address | `lat`, `lng`, `address` | No — GPS must not block submit |

No email. No password. On 200 replace token; status `pending_review` → waiting. Blocked on SP-03 for refs; OTP can ship on SP-01.

### Waiting / home / logout

Waiting: «طلبك قيد المراجعة», refresh session, logout.  
Empty home: shop name + «المنتجات بعد الموافقة». No fake grid.  
`POST /app/auth/logout` — wipe token even if the call fails.

## Out of scope

Catalog, cart, orders, payments, loyalty, channel names on products.

## Done

1. Invalid phone → Arabic 422 on the field.  
2. New number → OTP → form → waiting.  
3. Approved shop → OTP → empty home.  
4. Logout → phone; OS back does not restore register with a live token.  
5. Kill app on waiting → splash → waiting (token in secure storage).

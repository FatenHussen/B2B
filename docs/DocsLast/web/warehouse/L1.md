## Provision (CLI, not UI)

```bash
php artisan warehouse:register-device wh-demo-token 4821 1 1 --label=dev-pc
```

```
NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000/api/v1
NEXT_PUBLIC_X_CLIENT=warehouse-web
NEXT_PUBLIC_DEVICE_TOKEN=wh-demo-token
```

Never render `DEVICE_TOKEN` in production DOM.

`b2b.deviceId` in **localStorage** (survives sign-out). Token in **sessionStorage**.

---

## PIN — `FE-WH-PIN`

`POST /warehouse/auth/device-login` `{ device_token, pin }` — pin `/^\d{4}$/`. Pad `min-h-16`. 401: shake, clear; **do not** say whether token or PIN failed. 200: show `warehouse.name` → `/home`.

Home: queues unlock in L3. **Do not** call `GET /warehouse/queues`. Sign-out clears Bearer only.

## Done

Correct PIN `4821` → name on home. Wrong PIN stays on pad. No `/queues` route. No register-device form.

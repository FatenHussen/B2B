## Build

**Brands** EP-SC-010A/B — algorithm sliders store **definition only**; no fake bestseller grid.

**Tree** EP-SC-011…013 — channel rows start at **level 2**. Sixth level → 422; disable “add child” on level 5. Reorder rollback on cycle.

**Products** EP-SC-014…018 — nested `pricing` integers; SKU unique per channel; `channel_limit_exceeded` banner; `inventory.*` flags only (**no on-hand qty**). Variants generate Cartesian; ignore sample `stock` until L3.

**Import** EP-SC-019 — always `dry_run=true` first; commit is a **new** idempotency key. Export EP-SC-020 → `job_id`.

**Pricing** EP-SC-030…034 — help text: `retailer ← group ← zone ← qty_tier ← base`. Qty-tier changes `unit_price`; line `discount` stays 0. Zone −5% is integer `-5`, not `0.95`. **Do not** call `/app/pricing/quote` from this origin.

**Cap** EP-SC-035 — store only.

**Offers** EP-SC-040…042 — types from catalog. Emptying last component **stops** the offer. Stop + `reason`. Performance page: **honest zeros** in L2.

`/home` may show cached product **counts**. Still no `GET /channel/dashboard`.

## Sub-orders — `FE-CH-SO` (SP-10)

State machine in the UI = `allowed_actions` from the server. Illegal click → 409 `illegal_transition`.

| EP | Action |
|---|---|
| EP-SC-060/061 | list + detail + timeline |
| EP-SC-062/063 | confirm / bulk-confirm (≤50) |
| EP-SC-064 | reject + required reason |
| EP-SC-065 | edit lines (pending or confirmed before pick) |
| EP-SC-066/067 | assign / reassign — 422 if rep off-duty or wrong zone |
| EP-SC-068 | schedule → postponed |
| EP-SC-069 | cancel (crit) |

Confirm reserves stock and **reveals channel name** to the retailer. Reassign after handover confirm → 409. SOD: confirmer must not be the later payment clerk (enforced L4, seed roles now).

`POST /platform/auth/login` — if `requires_2fa`, keep `challenge_token` in **React state only** → `/login/2fa`. 401 generic.  
`POST /platform/auth/2fa/verify`. Boot `GET /platform/auth/me`. Logout `POST /platform/auth/logout`.

## IAM

Permissions catalog + holders. Roles: preview → create as **`draft`** → another user approves. Builtin not deletable. Assignments max 50; show assigned vs rejected. Simulate read-only. Temp grants ≤ 240 min, `reason` ≥ 20 chars. SoD list read-only. Approval inbox. Audit + export job. Access review: cannot close while items undecided.

---

## References

Pattern: list → create → update (`reason`) → enable/disable (**impact counts**, then confirm). **No hard delete.**

Governorates, zones (`filter[governorate_id]`; zone status is EP-AD-034), activity types, root categories, sale units, equipment, currencies. Zone disable: show `affected.retailers / reps / open_orders` before confirm.

FX `rate` is an integer. Display currency replace, not reprice of open orders.

Import: `dry_run=true` first; execute with a **new** idempotency key.

---

## Channels

List filters from the server (zeros OK; **never invent GMV**). Export = active filters.

Create EP-AD-051: returns `provisioning` + `provisioning_job_id` quickly — **poll** GET until `active` or retry EP-AD-053.

Card tabs (DOC-07): overview, users, manager invite reset (crit), coverage, warehouses read, features read, usage (`range=30d`, empty OK), limits, status buttons from `allowed_next` only (no `active→archived` control), export, delete only if `archived` (name + password + 2FA + second approver) → `deletion_request_id`.

Join applications: approve/reject + plan + trial → channel `provisioning`.

KPI tiles: print server zeros or hide. No fake sparklines.
